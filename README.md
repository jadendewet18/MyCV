# MyCV - Personal Online Curriculum Vitae

MyCV is a clean, modern, and responsive online CV built using HTML5, CSS3, and Bootstrap 5. It showcases my background as a software engineering student and freelance photographer, highlighting my technical skills, soft skills, education, work experience, and personal projects.

## 🚀 Live Demo

Check out my live online CV here:
[https://jadendewet18.github.io/MyCV/](https://jadendewet18.github.io/MyCV/)

## ✨ Key Features

- **Responsive Design:** Optimized for mobile, tablet, and desktop viewports using Bootstrap 5.
- **Personal & Professional Content:** Structured layout containing an About Me bio, work history, education, and contact details.
- **Skills Showcase:** Visual badge indicators for both technical competencies (Python, Django, REST APIs) and soft skills.
- **Modern UI Styling:** Styled with Google Fonts (*Plus Jakarta Sans*), custom card containers, and Bootstrap Icons.

## 🛠️ Built With

- **HTML5** - Page structure and semantic layout
- **CSS3** - Custom design enhancements and styling
- **Bootstrap 5** - Responsive grid system and utility components
- **Bootstrap Icons** - Visual iconography
